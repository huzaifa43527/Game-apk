🎯 Number Guessing Game

A simple and interactive Number Guessing Game developed in Python. The game generates a random number within a selected range and challenges the player to guess it within a limited number of attempts.

The project started as a basic Python console-based game and was developed into a complete interactive application with a user-friendly interface and additional gameplay features.

🎮 Features

- 🎯 Random number generation
- 🔢 Multiple number ranges
- 🎚️ Different difficulty levels
- 💡 Helpful guessing feedback
- 🔥 Hot/Cold style hints
- ⏱️ Time-based challenges
- 🏆 Score system
- 🔥 Winning streaks
- 🏅 Achievements
- 📊 Player statistics
- 🪙 Reward/coin system
- 📅 Daily challenges
- 🔄 Reverse guessing mode
- ⚙️ Game settings
- 🎨 Interactive user interface

🕹️ How to Play

1. Start the game.
2. Select a game mode or difficulty level.
3. The system generates a secret random number.
4. Enter your guess.
5. The game provides feedback based on your guess.
6. Continue guessing until you find the correct number or run out of attempts.
7. Your score and game result are displayed at the end.

🎯 Game Logic

The core game generates a random number and compares it with the player's input.

- If the guess is lower than the target number → Too Low
- If the guess is higher than the target number → Too High
- If the guess matches the target number → Correct!

The player must find the number within the available attempts.
